2. SCOPE FOR THE SALESFORCE CONFERENCE IS DECIDED

We're demoing this site, with a marketplace of three plugins:

- Governance plugin - skills that show the systemprompt governance story: scope checks, secret scanning, blocklists, rate limits, human approval. This is the differentiator; it has to be the sharpest of the three.

- Agentforce-equivalent plugin - the same tasks Agentforce does, done through systemprompt, at materially lower cost and higher throughput. The comparison is the point, so we need real numbers we can stand behind on stage.

- CRM plugin - the one we actually use internally. Live systemprompt leads and clients, and everyone on the team adding what they learn into a shared brain.

The aim is not more surface area. It's that these three work, every time, fast, with no caveats. 100% confidence.

3. THE REAL PROBLEM: THERE IS TOO MUCH, AND NOT ENOUGH OF IT IS GOOD

Right now the marketplace carries roughly eighteen enabled skills across four plugins, and a lot of it is junk - half-finished, overlapping, or doing one small thing that belongs inside a bigger skill. I've already folded some of it together (add_note, schedule_activity, manage_tasks and manage_calendar are now inside crm and manage_work; nine admin skills became report / inspect / manage_platform), so the screenshots below already show some names that are gone.

Where I want to land: 10-15 skills total. Three plugins, about five skills each - CRM, Agentforce-equivalent, and demo/governance. Five per plugin, and each one has to be the single most impactful thing in its category. Every one of those needs:

- an artifact worth looking at
- a designed inline result, not a JSON dump
- to run fast and not fail

Everything else gets disabled. I'd rather ship five things that make someone lean forward than fifteen that make them squint.
